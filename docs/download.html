Tải Trạm in EasyPOS

Cài một lần trên máy tính nối với máy in. Sau đó Agent tự cập nhật, không cần tải lại.

Windows

Windows 10 / 11 (64 bit) · bản mới nhất

Tải bộ cài Windows
  1. Mở tệp vừa tải, bấm Yes khi Windows hỏi quyền quản trị.
  2. Bấm Next tới khi xong, chọn mở Trạm in.
  3. Đăng nhập bằng tài khoản EasyPOS, cắm máy in USB hoặc chọn máy in mạng.
Windows báo "không xác định nhà phát hành"?

Bấm Thông tin thêm rồi Vẫn chạy. Đây là cảnh báo chung cho phần mềm mới chưa đủ lượt tải.

Linux (Ubuntu / Debian)

64 bit · bản mới nhất

Tải gói .deb
  1. Mở Terminal tại thư mục tải về, chạy: sudo apt install ./easypos-print-agent_amd64.deb
  2. Rút và cắm lại máy in USB, mở "Trạm in EasyPOS" trong menu ứng dụng.
  3. Không cần cài driver hãng — Agent in thẳng qua cổng USB của hệ điều hành.

Cần hỗ trợ? Mở Trạm in, vào mục "Chọn máy in" — nếu máy in cắm rồi mà không thấy, Trạm in sẽ ghi rõ lý do và cách xử lý. Các bản cũ: tất cả bản phát hành.
